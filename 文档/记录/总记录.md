# Matcher 多批次实验总记录

本文件汇总 Matcher 第 0–5 批实验的稳定结论和索引。逐条故障、诊断命令与修复经过保留在 [Matcher 单候选闭集身份分类重写执行记录](../exec_plan/Matcher_单候选闭集身份分类重写执行记录.md)；本目录只保存便于比较的三层实验账本。

## 不变边界

- 开发、选模和头对头比较只读取 validation；calibration 清单与缓存可以作为非评估准备，但模型推理必须等全部迭代结束且用户再次明确确认。
- 只管理 Job `340893/340894/340895/340897/340898/340899` 占用的 6 张 GPU；不修改用户自行提交的任务。
- 所有 allocation 的 `after_lock` 必须保留。新实验按批次编号优先填充空闲 GPU，不跳过尚未提交的更早批次任务，不擅自重复任务。
- 候选为训练与评估单位；训练候选全局随机排列，不按 PDB 分组；global batch 固定为 32。
- 每批使用独立 W&B project 或 group；指标名第一层按损失、梯度、门值、学习率、性能、显存、统计分母、六分类、身份层次、区域和选模拆分，保证 W&B 默认工作区能直接形成职责区块。
- 五类总体和逐类端到端身份指标只把六分类作为背景/任一前景门；五个前景子类是中间辅助量。小分子兼容报告仍要求六分类预测为 `small_molecule`，保持第 0 批口径。

## 第 3 批开发状态

- 四模态各自新增 `Linear(4,D_m) → SiLU → Linear(D_m,K)` 注意力偏置 MLP，输入为相对 XYZ 与 Stage1 固化概率，末层权重和偏置采用零初始化。
- 新分支初始化使用隔离随机流，未增强与增强模型的共同参数初值保持逐值相同；FP32/BF16、空模态和补零掩码等价性已有回归。
- 当相应模态含有效 token 且损失沿该分支回传时，A/P/V 偏置末层权重首轮可学；PP 维持严格零增量，并按先输出投影权重、后偏置末层权重的两步顺序唤醒。末层 `bias` 只产生 softmax 常数平移，不称作被唤醒。
- 四份配置使用独立 W&B project `AdaLigand-Matcher-Batch3`。W&B 分别记录全局梯度裁剪后的偏置末层权重梯度范数和同次更新后的权重范数；整批无有效 token 的模态省略两项。
- 首个冻结候选通过 pytest `86 passed`，科学终审为 PASS；严格技术表达终审要求补齐诊断时序、张量契约、YAML 自包含性、随机流测试和账本状态。集中修订后的最终快照通过 pytest `93 passed`、mypy 38 个源码文件零问题、compileall、pyflakes、19 份 YAML 正式解析、49 个 shell 的 `bash -n` 和 diff-check；科学正确性与严格技术表达两项独立复审最终均为 PASS，阻断项为零。
