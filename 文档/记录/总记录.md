本文件汇总 Matcher 第 0–5 批实验的稳定结论和索引。逐条故障、诊断命令与修复经过保留在 [Matcher 单候选闭集身份分类重写执行记录](../exec_plan/Matcher_单候选闭集身份分类重写执行记录.md)；本目录只保存便于比较的三层实验账本。

## 不变边界

- 开发、选模和头对头比较只读取 validation；calibration 清单与缓存可以作为非评估准备，但模型推理必须等全部迭代结束且用户再次明确确认。
- 只管理 Job `340893/340894/340895/340897/340898/340899` 占用的 6 张 GPU；不修改用户自行提交的任务。
- 所有 allocation 的 `after_lock` 必须保留。新实验按批次编号优先填充空闲 GPU，不跳过尚未提交的更早批次任务，不擅自重复任务。
- 候选为训练与评估单位；训练候选全局随机排列，不按 PDB 分组；global batch 固定为 32。
- 每批使用独立 W&B project 或 group；指标名第一层按损失、梯度、门值、学习率、性能、显存、统计分母、六分类、身份层次、区域和选模拆分，保证 W&B 默认工作区能直接形成职责区块。
- 五类总体和逐类端到端身份指标只把六分类作为背景/任一前景门；五个前景子类是中间辅助量。小分子兼容报告仍要求六分类预测为 `small_molecule`，保持第 0 批口径。

## 第 0 批稳定结论

- 候选六分类：mean/max validation macro-F1 `0.5304244533`，未增强候选条件交叉注意力 `0.5269085347`。
- 完整 Matcher 第一名：SMI-TED Light 289M detached，selection score `0.6696320918`；第二名 SMI-TED oracle 为 `0.6654351100`。差值只来自单随机种子，不能解释为稳定的损失排序。
- SMI-TED joint 对应 Job `340896` 在分配前取消且按用户要求跳过；它是缺失实验，不是零分或失败结果。
- I/O 优化后的正式起点为 train/validation 各 4 个 spawn、非持久 DataLoader 工作进程，PP 命中后不读取完整 probability map；每个 YAML 仍可显式改变工作进程与缓存参数。
