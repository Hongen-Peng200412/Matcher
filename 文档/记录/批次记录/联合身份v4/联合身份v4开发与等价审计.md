# 联合身份 v4 开发与等价审计

## 依据与范围

本工作依据 [目标草案](../../目标草案.md) 中 2026-08-15 的联合身份要求，把一个模型可见身份定义为 `(object_key, PreparedLigand.smiles)`。`PreparedLigand.smiles` 是 AdaLigand `prepared_smiles.jsonl` 的顶层公开模型接口字符串；不使用 occurrence 坐标、`present` 掩码、沉积原子选择或语言归档中的 `model_smiles`。

本轮只开发和审计 train/validation。正在运行的第 5 批继续冻结 `closed_set_v3`，不得热替换清单；calibration 不参与清单比较、模型推理、指标计算或方案选择。

## 科学契约

- 相同 `object_key`、不同顶层 `smiles` 建立不同身份槽；相同 `smiles`、不同 `object_key` 不合并。
- LigandObject 图仍只由 `object_key` 定位，因此不同联合身份可以安全复用同一张模板图。
- 语言向量必须来自联合身份中顶层 `smiles` 完全相同的 occurrence；选择规则沿用 v3 的 `(pdb_id,object_key,language_family)` 盐值，使没有拆分的组保持固定 occurrence。
- 顶层 `smiles=null` 不建立 `(object_key,null)` 身份，也不能借用同模板其它 occurrence 的非空身份。整个 `prepared_smiles.jsonl` 缺失用 `missing_file` 单独标记；已有文件缺记录或字段损坏时失败关闭。
- 同一 PDB 的身份轴内，一个 `(object_key,prepared_smiles)` 只能对应一个 `class_name/class_index`；同一小写 `pdb_id` 的候选记录不得同时发布到多个划分，仅出现在 `excluded_pdb.jsonl` 的整 PDB 排除记录不构成候选重叠。不同 PDB 的局部类别差异不阻断，但必须在 manifest 与一次性审计报告中结构化列出。
- seen 标记按 `(object_key,prepared_smiles,language_family)` 计算；跨 PDB 的不同字符串不会互相继承训练可见性。

## 真实数据等价门禁

一次性清单审计工具位于 Git 忽略目录 `tmp/joint_identity_v4_audit/audit_manifest_equivalence.py`。它只读取显式传入的 v3/v4 train/validation JSONL、occurrence 主表和对应 PreparedLigand 记录，先独立重建 v4 联合身份，再逐 PDB 比较候选键集合与顺序、身份槽、固定语言 occurrence、seen 标记和两种语言的有效监督数量。错误字符串、错误状态、缺失身份槽或已有 PreparedLigand 文件缺记录会失败关闭；候选集合变化会进入结构化差异报告。它不导入模型、不读取 calibration，也不进入正式训练入口。该工具允许在 diagnostics 报告中使用文件摘要，但摘要及服务器发布取证不得进入正式 `matcher` 包、YAML 或 `resolved.json`。

真实审计分两层：

1. 清单层先给出受影响 PDB、身份、occurrence、候选和有效监督数量。若没有差异，全部 PDB 进入数值等价；若有差异，只把未受影响 PDB 送入严格等价门禁，并逐项人工审阅受影响 PDB。
2. 数值层比较 Dataset 科学张量、固定权重前向输出，以及评估的 `loss`、`metrics`、`sample_count`、`identity_eligible_count`。墙钟耗时、吞吐、schema、路径、摘要、时间戳和新增字符串元数据不要求逐值相同。

真实审计 Job `342318` 已发布完整报告并因 `--require-zero-affected` 以预定的非零状态结束。两个划分的候选数、身份数、候选集合与顺序、固定 occurrence、可监督候选数和排除记录全部相同，没有同 PDB 多 SMILES 拆槽。唯一差异是同一 `CCD:SAH` 联合键在 `train/7pnx` 与 `validation/7pnz` 的两种语言 seen 标记均由 false 变 true；每个 PDB 的 seen 身份数增加 1，但可监督候选数不变。该变化来自 `train/7fgg` 的 exact 联合键正身份，只允许改变 validation seen/unseen 分层统计，不应改变训练、前向、总体指标或 selection score。下一步对两个受影响 PDB 全部候选与未受影响分层样本做 Dataset 精确比较，再在同一 GPU 上比较固定权重前向和完整 validation 科学结果。
