# 联合身份 v4 记录目录

本目录记录 Matcher 从 `closed_set_v3` 的模板身份迁移到 `closed_set_v4` 联合身份的开发、真实数据等价审计、零门基线和学习率复现。它不追改已经自然收口的第 5 批 v3 结果。

- [联合身份 v4 开发与等价审计](联合身份v4开发与等价审计.md)：保存契约、实现范围、清单/Dataset/GPU 等价门和当前六项训练状态。
- [train/validation 清单 v4 构建与等价审计](../../单任务记录/联合身份v4/train_validation清单v4构建与等价审计.md)：保存 CPU Job、release、提交命令和真实清单证据。
- [学习率复现单任务记录](../../单任务记录/联合身份v4/学习率复现/README.md)：保存三个随机种子的 `LR=1e-4/2e-4` 配对、Job、launch、W&B 和运行根。
- [摘要拼接六项实验](摘要拼接六项实验.md)：保存 mean/max 与候选条件注意力摘要拼接的六项矩阵、Git/release 门禁、受保护触发和首步状态。
- [摘要拼接单任务记录](../../单任务记录/联合身份v4/摘要拼接/README.md)：保存六项任务各自的配置、Job、launch、W&B、运行根、首步和最终结果。

本目录不保存 calibration 结果。calibration 模型推理与正式指标仍需用户在全部迭代结束后单独确认。
