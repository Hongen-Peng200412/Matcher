# 联合身份 v4 记录目录

本目录记录 Matcher 从 `closed_set_v3` 的模板身份迁移到 `closed_set_v4` 联合身份的开发、真实数据等价审计和后续零门基线。它不是已经获批的“第 6 批”，也不改变正在运行的第 5 批六项任务。

- [联合身份 v4 开发与等价审计](联合身份v4开发与等价审计.md)：保存契约、实现范围、本地门禁、一次性审计边界和待完成事项。
- 后续只有在真实 train/validation 审计、科学正确性审查和严格技术表达审查均通过后，才会新增零门基线的单任务记录。

本目录不保存 calibration 结果。calibration 模型推理与正式指标仍需用户在全部迭代结束后单独确认。
