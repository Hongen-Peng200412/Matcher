# 第 1 批：五类身份扩展与固化手动特征

## 任务定义

本批使用 SMI-TED Light 289M、mean/max 聚合，从零训练 oracle、detached、joint 三个完整 Matcher。身份监督由 small_molecule 扩展到 `ion/nucleotide_like/peptide_like/small_molecule/sugar` 五类非背景配体；背景候选不进入身份损失。

## 实现边界

- 配置必须显式选择 `identity_scope=small_molecule` 或 `identity_scope=all_non_background`；旧模式保留用于同口径复现。
- 对真实身份 `L`，detached/joint 使用 `softmax(z_G)[c(L)]`，oracle 使用 1；分母仍是有图、有当前语言表示且目标有效的真实候选数。
- 候选仍参与六分类和区域监督，即使其真实身份缺图或语言表示。
- A/P 使用完整 80³ token；第 1 批 V/PP 仍使用固定 `[16,64)³`。每种模态拼接 token 数及 Stage1 固化概率均值/最大值；空模态三项均为 0，计数在进入网络前使用 `log1p`。
- 身份匹配 MLP 同时读取上述候选统计和 `stopgrad(softmax(z_G)[c(L)])`；该特征不能把身份损失梯度传回六分类头。
- validation 同时报告旧 small_molecule-only 清单中的兼容指标、五类共享清单总体指标、五类逐类指标与有效监督数。

## W&B 组织

本批使用独立 project `AdaLigand-Matcher-Batch1`，group `matcher-batch1-five-class-manual-features`。W&B 默认按指标名第一个 `/` 前缀建立区块，因此第一层使用可直接识别的职责名称：

- `loss/*`：train step、train epoch 与 validation 的总损失和四个分项；
- `gradient/*`、`gate/*` 与 `learning_rate/*`：裁剪前梯度、身份分支梯度、两个门值和学习率；
- `performance/*`、`memory/*` 与 `statistics/*`：数据等待、GPU 计算、吞吐、墙钟、显存和各类分母；
- `classification_summary/*`、`classification_per_class/*` 与 `classification_confusion/*`：六分类汇总、逐类 precision/recall/F1/分母及 36 项混淆计数；
- `identity_configured/*`、`identity_small_molecule/*`、`identity_all_non_background/*` 与五个 `identity_<class>/*`：配置范围、小分子兼容范围、五类总体和逐类身份报告；
- `area/*` 与 `selection/*`：区域指标和选模状态。

完整嵌套报告仍逐 epoch 写入 `history.jsonl`；W&B 在线曲线不替代该 JSONL 证据。

## 身份指标口径

- `intrinsic` 忽略六分类结果，在对应身份清单中计算 Top-K。
- `conditional` 只统计六分类精确判对真实子类的候选，用于诊断五个中间辅助类别。
- 五类总体与五个逐类 `end_to_end` 只把六分类的背景/任一前景判断作为门：预测为任一前景类且 Matcher 选中真实身份即为成功，不要求六分类子类精确。逐类预测阳性按 Matcher 最终 Top-1 身份类别归桶。
- `identity_small_molecule/*` 使用只含小分子身份的输出槽，并要求六分类预测为 `small_molecule`，提供与第 0 批同清单、同分母的兼容口径；它复用五类模型前向，不是另行执行旧 small-only 模型。
- 真实前景但 `identity_target=-1` 的候选不进入身份分母；背景被误判为前景且存在可选身份槽时计入端到端假阳性。
