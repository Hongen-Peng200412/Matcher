# 第 3 批：增强候选条件注意力

## 目标与对照

本批只使用 train/validation，单独考察“实体相对 XYZ + Stage1 固化概率”生成的注意力分数偏置。三种完整 Matcher 使用第 2 批同损失的 mean/max 任务作为预算内基线；增强六分类与第 2 批未增强候选条件注意力直接比较。由于预算不增加三项未增强完整 Matcher，最终需要联合六分类直接对照与完整 Matcher 结果判断增强注意力是否值得保留。

## 冻结科学变量

- 四模态分别使用独立 `Linear(4,D_m) → SiLU → Linear(D_m,K)`，输入顺序为相对 XYZ、Stage1 固化概率。
- 最后一层权重和偏置采用零初始化；增强模型初始化时逐值退化为未增强注意力，不增加额外门控。
- PP 原有输出投影继续零初始化。当 PP 含有效 token 且损失沿该分支回传时，第一次反向先让输出投影权重获得非零梯度；更新后下一次反向才让偏置 MLP 末层权重获得非零梯度。
- 第 2 批的 V 质心视野、12 项手动统计、4 项采样统计、候选集合、监督、global batch 和优化器保持不变。
- W&B 分别记录全局梯度裁剪后的偏置末层权重梯度范数，以及同次更新后的末层权重范数；整批无有效 token 的模态省略两项。
- 末层 `bias` 只对一个注意力头的全部 token 产生常数平移，数学上不改变 softmax，因此不监控也不称作被唤醒。

## 当前开发证据

- 四个偏置 MLP 参数互不共享，末层采用零初始化；新增分支的初始化随机流被隔离，不改变未增强模型后的随机状态或共同参数初值。
- FP32/BF16 下，非空、部分补零和空模态的增强输出在初始化时都与未增强输出逐元素相等。
- 补零 token 的偏置输入任意改变都不影响输出。当相应模态含有效 token 且损失沿该分支回传时，A/P/V 偏置末层权重在第一次反向传播获得非零梯度；PP 按“先输出投影权重、后偏置末层权重”的两步顺序唤醒。
- 正式 YAML 强制显式填写偏置开关；第 0–2 批 checkpoint/resolved 缺该字段时只在历史产物恢复入口迁移为 `false`。
- 首个冻结候选通过 pytest `86 passed`，独立科学终审为 PASS；严格技术表达终审发现五组契约与测试表述阻断。集中修订后的最终快照通过 pytest `93 passed`、mypy 38 个源码文件零问题、compileall、pyflakes、19 份 YAML 正式解析、49 个 shell 的 `bash -n` 和 diff-check；科学正确性与严格技术表达两项独立复审最终均为 PASS，阻断项为零。
