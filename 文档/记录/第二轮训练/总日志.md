本记录追踪 `strongest-1`、`blob_only-0`、`density_only-0`、`density_only-106` 与 `pocket_only-0` 的实现、机械门禁、正式训练、两套测试集评测和双线 Git 收口。科学规格来自 `matcher/model/raunet.py` 中已经用户确认的 TODO、`talk_new/反馈/9-19小分子测试计划.md`、新增消融的用户冻结定义和 `测试结果与追溯/记录规则与说明.md`。本轮不重建 train/validation、held_out_test_0 或 Stage3 小分子 manifest。

## 已冻结决定

- `strongest-1` 删除 RAUNet 末端三路多尺度卷积, 直接使用 64 通道最高分辨率解码特征。
- `strongest-1` 为 A、P、PP 建立三个初值为 `0.01` 的独立可学习标量门, 同时控制对应 token 和 count/mean/max 统计; V/blob 不加门。
- `blob_only-0` 的候选侧只读取 V/blob token、V 的 count/mean/max 和四项裁剪统计; 不读取密度、受体、区域目标, 不建立 U-Net、体素调制器或区域头。身份侧仍使用 SMI-TED、SMILES 图和同 PDB 身份清单。
- `strongest-1` 的修订正式损失权重为前景 `0.30`、ligand-area `0.00`、binding-area `0.00`、SMILES 身份 `1.00`；其模型输入、RAUNet、A/P/V/PP 门、区域头和其余科学字段不变。旧 `0.30/0.05/0.05/1.00` 运行只保留为被取代的中断证据。`blob_only-0` 同样使用 `0.30/0.00/0.00/1.00`。
- 选模公式为 `selection = (0.3 * foreground_PRAUC + supported_foreground_SMILES_accuracy) / 1.3`。有效改善门槛仍为 `0.001`。
- `patience=3` 表示连续三次 validation 未达到有效改善只累计状态, 第四次才触发降低学习率或早停。
- H100 Job `378587` 使用 30 个活动 DataLoader worker; A800 数组任务 `379403_1` 使用基础锁编号 `379403` 和 15 个活动 worker。训练与 validation worker 不并存。
- 全测试集使用 BEST 保存的 validation 前景阈值; Stage3 小分子评测按冻结契约忽略前景头, 只检查精确 SMILES 身份。两者都不读取 calibration。
- `density_only-0` 候选侧只读取单通道实验密度并使用 RAUNet 空间 mean/max 摘要；`pocket_only-0` 候选侧只读取原始 50 维 A_feat_L0。两者均不建立区域头，损失权重为 `0.30/0.00/0.00/1.00`，并在 A800 上按此顺序执行。
- strongest-1 的模型输入、RAUNet、A/P/V/PP 门和区域头保持不变，但正式优化目标修订为 `0.30/0.00/0.00/1.00`；旧 `0.30/0.05/0.05/1.00` 运行只作为被新契约取代的中断证据。
- `density_only-106` 只使用 56 通道完整密度 bank 与 50 通道受体特征网格，复用 density_only 的 RAUNet 空间 mean/max 直接摘要；不读取 token、人工统计或区域标签，不建立区域头。
