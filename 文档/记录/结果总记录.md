# Matcher 实验结果总记录

本记录汇总 Matcher 第 0–5 批、联合身份 v4、学习率复现和摘要拼接实验的稳定 validation 结果。截至 2026-08-16，已经批准的训练全部自然早停，不再新增实验；正式 calibration 划分没有被读取，也没有参与模型选择。

## 比较口径

- 完整 Matcher 的 `selection score` 是模型早停和主要排序分数，定义为六分类 macro-F1、条件身份 Top-1 与宽松端到端身份 F1 的算术平均值。
- 表中的模型结果均取各任务自然早停时保存的 BEST validation；`BEST/last` 表示最佳 epoch 和触发 patience 早停的最后 epoch。
- 候选预训练任务把六分类 macro-F1 直接作为自身的 `selection score`，同时仍评估 ligand/binding 两项区域 loss 与 Dice；它不产生身份指标。该单项标量不能与完整 Matcher 的三项复合 `selection score` 直接比较。
- 同一硬件、同一训练 seed、同一清单和同一优化设置的成对任务用于直接归因；跨硬件或跨 seed 的数值只提供重复证据。
- `clip200` 表示 `gradient_clip_norm=200`。只有实际裁剪触发比例不超过 `0.1%` 时，指定轨迹才可称为近似不裁剪；阈值名称本身不构成证明。
- 联合身份 v4 使用 `(object_key, PreparedLigand.smiles)`。其中 `PreparedLigand.smiles` 是 PreparedLigand 顶层公开接口字符串，不是 `model_smiles`。

## 结果总览

最高 validation `selection score` 为 `0.7057373298`，来自 A100、training seed `3409`、SMI-TED、oracle、联合身份 v4、摘要拼接、零身份门、LR `1e-4`、clip200、从零训练。它相对第 2 批 mean/max oracle 的 `0.6981048482` 高 `1.093315%`。

三组零门 clip200 的严格结构配对中，摘要拼接相对 mean/max 的 selection 变化为 `+0.375438%/+0.352861%/+1.906471%`，平均为 `+0.878257%`。三组方向一致，但绝对提升的总体标准差约为 `0.005037`，且 seed3409 贡献了大部分收益，因此结论是“小幅正收益、训练方差明显”，不是确定的大幅改进。

CPU 清单、Dataset、Batch 和同卡 GPU 门禁均已通过。固定第 2 批 checkpoint 时，v3 与 v4 的 validation 长度和 `sample_count` 都为 `6495`，`identity_eligible_count` 都为 `1466`，selection 都为 `0.69798148434599`；固定前向、完整科学 validation、checkpoint 身份、GPU、数值后端和缓存清单严格一致。该证据允许后续实验采用联合身份 v4，但不把 schema 与清单摘要的字节变化称为文件级等价。

## 摘要拼接严格结构配对

摘要拼接把 mean/max 产生的候选表示与候选条件注意力产生的候选表示拼接，再通过零输出残差加回 mean/max 主表示。零输出初始化使新结构在初始化时退化为 mean/max 前向；训练后由严格配对判断结构收益。

| 硬件与 training seed | mean/max、零门、clip200 | 摘要拼接、零门、clip200 | 摘要拼接绝对变化 | 摘要拼接相对变化 |
| --- | ---: | ---: | ---: | ---: |
| A800、`3407` | `0.6889974930159317` | `0.6915842525509563` | `+0.0025867595` | `+0.375438%` |
| A100、`3408` | `0.6944095969666253` | `0.6968598986464777` | `+0.0024503017` | `+0.352861%` |
| A100、`3409` | `0.6925343658028632` | `0.7057373297694586` | `+0.0132029640` | `+1.906471%` |

三组平均绝对变化为 `+0.0060800084`；mean/max 与摘要拼接的组均值分别为 `0.6919804853/0.6980604937`。selection、总体固有身份 Top-1、宽松端到端身份 F1 和 small-molecule 三项身份指标在三组中均同向提高；六分类 macro-F1、条件身份 Top-1 和 ligand Dice 各有一组反向，binding Dice 三组均提高但基线很低，不能只依据相对百分比判断区域质量。

当前最高分任务的 BEST validation 指标为：六分类 macro-F1 `0.5336984208`、固有身份 Top-1 `0.8847203274`、条件身份 Top-1 `0.8935264055`、宽松端到端身份 F1 `0.6899871630`；small-molecule 的固有 Top-1、条件 Top-1、端到端 F1 为 `0.7944954128/0.8271334792/0.7078651685`；ligand/binding micro-Dice 为 `0.2962360015/0.0629469791`。

完整矩阵、逐任务证据和相对变化见[摘要拼接实验记录](批次记录/联合身份v4/摘要拼接六项实验.md)与[摘要拼接单任务索引](单任务记录/联合身份v4/摘要拼接/README.md)。
