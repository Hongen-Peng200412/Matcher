# 全测试集结果总览

本文按评估口径比较已经完成冻结评估的第一轮模型与第二轮 `strongest-1`、`blob_only-0`、`density_only-0`、`density_only-106`、`pocket_only-0`，而不是重复实验运行流水。所有数值来自正式 `frozen_test.json`、BEST checkpoint 元数据和训练摘要；结果整理没有重新训练、重新推理、读取 calibration 或在测试集拟合阈值。

## 评估数据与固定口径

- 主结果是完整 `held_out_test_0`，固定包含 179 个 PDB。真实受体条件前向 2,251 个全部 centered 候选，其中 1,653 个为 selected 候选；CryoAtom2 条件前向 2,407 个全部 centered 候选，其中 1,651 个为 selected 候选。
- 官方 `test_1` 固定包含 149 个 PDB。它只从同一次 `test_0` 冻结前向中筛选，不执行第二次模型前向。
- 前景 PRAUC 和 F1 统计 selected 候选。F1 使用各实验从 BEST validation 冻结的阈值，不在测试集重新拟合。
- SMILES 匹配准确率只统计真实前景且身份资产受支持的 selected 候选。`9ian` 与 `9oq7` 的不受支持身份候选保留 Stage1 排名并进入前景评价，但退出 SMILES 准确率分母。
- top-k 对每个 PDB 先排列全部 `candidate_selected=True` 候选，再追加全部 `candidate_selected=False` 候选。Gaussian 使用 `candidate_score`，来源概率均值使用 `source_probability_mean`。Stage1+Matcher 不重排候选，只增加前景正确与 SMILES 正确条件。
- Stage1-only 的 PDB 命中定义为：前 k 个候选中至少一个候选与任一真实 occurrence 的候选覆盖率和 occurrence 覆盖率均不低于 0.30。top-k 分母始终固定为 179。

## 真实受体与 CryoAtom2 的差异

三个实验在 CryoAtom2 条件下的前景 PRAUC 与固定阈值 F1 都低于真实受体条件，说明 Stage1 受体来源变化主要影响前景判别。SMILES 匹配准确率并没有同幅下降：`strongest-0` 在 CryoAtom2 条件下反而略高，`dense_blob_only-0` 只略低，`blob_only-0` 下降约 0.0051。这个对照表明前景判断与真实前景内部的闭集 SMILES 匹配是两个不同问题，不能用单一指标概括。

分类结果还显示，`sugar` 的 SMILES 匹配准确率在两个模型和两种受体条件下都明显低于 `small_molecule` 与 `ion`。`peptide_like` 在 test_0 只有 1 个支持样本，`nucleotide_like` 没有支持样本，因此不能从其 1.0 或空值推导类别泛化结论。

## Stage1-only、Stage1+Matcher 与 Emap2lig 的关系

- Find_1 Stage1-only 只检查覆盖命中，不要求 Matcher 的前景或 SMILES 决策正确。
- Stage1+Matcher 沿用完全相同的 Find_1 候选顺序，并增加前景判断与 SMILES 匹配条件。因此其命中数不高于 Stage1-only 是契约预期，而不是 Matcher 重新排序造成的退化。
- Emap2lig 是 density-only、receptor-independent 的单条 Stage1-only 基线，使用实例内原生 ligand probability 均值排序。两种 top-k 图和两个实验中的 Emap2lig 数组逐字段相同。
- Emap2lig 与 Find_1 的候选集合和候选生成方式不同。它适合作为冻结外部基线，但曲线差异不能单独归因于 receptor、排序分数或 Matcher。

## 有限结论

在完整 test_0 上，`strongest-0` 的前景 PRAUC 仍最高，而 `strongest-1` 的真实受体 SMILES 准确率最高；两者没有形成同一指标上的全面支配。`blob_only-0` 在不读取密度与受体信息时仍保持接近的完整测试表现。`density_only-106` 的结果证明体素-only 路径仍具有较强辨别能力，但没有超过多模态或 blob-only 主结果；`density_only-0` 与 `pocket_only-0` 的总体身份准确率明显较低。多数 top-k 差异只有数个 PDB，当前证据支持按指标和使用条件描述局部优势，不支持夸大为全面胜负。
