# 追溯与说明：pocket_only-0

## 实验身份与科学契约

`pocket_only-0` 的代码变体为 `pocket_only`。候选侧只读取原始 50 维 `A_feat_L0`，经 token 投影和掩码 mean/max 形成候选表示；不读取 A probability、坐标、L1/L2/L3、密度、V、P、PP 或候选人工统计，也不实例化 RAUNet、区域头、体素调制器或候选模态聚合器。身份侧、前景头和直接 SMILES 身份交叉熵与正式主线一致。训练损失权重为 `0.30/0.00/0.00/1.00`。

BEST 公式是 `(0.3 × 前景 PRAUC + SMILES 匹配准确率) / 1.3`。前景 F1 不参与选模；阈值 `0.53515625` 只由 BEST validation 拟合。扩展 top-k 先 selected、后 unselected；Matcher 不改变 Stage1 顺序。
