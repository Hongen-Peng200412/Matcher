# 实验结果：Emap2lig

## 实验身份

| 字段 | 内容 |
| --- | --- |
| 实验标识 | `Emap2lig` |
| 正式方法 | Emap2lig v0.3.4 官方 `Emap2lig-Find` |
| 在 Matcher 比较中的角色 | Stage1-only 外部基线 |
| 输入边界 | density-only、receptor-independent；不读取真实受体或 CryoAtom2 受体模型 |
| 候选排序 | 按每个官方实例内原生 ligand probability 的均值降序排列 |

本档案只回答一个问题：在 Matcher 正式 `held_out_test_0` 比较使用的 179-PDB、双向覆盖阈值 0.30 和 `k=1,…,20` 口径下，Emap2lig 的 Stage1-only top-k 表现是多少。

## 完整 held_out_test_0（179 PDB）

## 不适用的 Matcher 指标

Emap2lig 没有 Matcher 功能，也不负责判断某个候选是不是假阳性。因此以下项目对本实验不适用，本档案不填零值或虚构替代指标：

- Matcher 候选前景二分类 PRAUC、F1 和冻结阈值；
- SMILES 总体或分类匹配准确率；
- Stage1+Matcher top-k；
- Matcher BEST checkpoint、validation selection 和早停结果。
