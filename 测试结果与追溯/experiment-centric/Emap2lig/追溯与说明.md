# 追溯与说明：Emap2lig

## 实验身份与 Matcher 比较契约

| 字段 | 正式值 |
| --- | --- |
| 实验标识 | `Emap2lig` |
| 上游方法 | Emap2lig v0.3.4 官方 `Emap2lig-Find` |
| 比较角色 | Stage1-only、density-only、receptor-independent 外部基线 |
| PDB 分母 | 179 |
| k 范围 | 1 到 20 |
| 双向覆盖阈值 | 0.30 |
| 候选分数 | 官方实例内原生 ligand probability 均值 |
| 分数并列规则 | 较小的 `source_blob_index` 优先 |

一个候选只有在以下两个比例同时不低于 0.30 时才命中某个真实 ligand occurrence：

1. 候选与 occurrence 的交集体素数除以候选体素数；
2. 同一交集体素数除以 occurrence 体素数。

某个 PDB 的 top-k 命中表示前 k 个候选中至少一个候选命中任一真实 occurrence。Emap2lig 的正式候选全部为 `candidate_selected=True`，因此 Matcher 的“selected 优先、unselected 追加”规则不会改变其原生排序。

生成过程调用 `matcher.evaluation.test_set.build_emap2lig_stage1_curve()`，对每个 `per_pdb/<pdb_id>.npz` 执行以下计算：

1. 用 `intersections`、`pred_sizes` 和 `gt_sizes` 重新计算双向 0.30 覆盖命中；
2. 按 `candidate_score` 降序、`source_blob_index` 升序得到唯一候选顺序；
3. 对 `k=1,…,20` 判断前 k 个候选是否至少命中一次；
4. 在固定的 179-PDB 集合上分别汇总命中数和命中比例；
5. 检查 top-3/4/5 必须严格复现上游官方汇总中的 87/89/90。

## 限制与解释边界

- 完整 top-1…20 曲线是 Matcher 评估器从 Emap2lig 正式逐 PDB evaluation NPZ 派生的比较产物；上游 `official_find_li.metrics.json` 自身只直接保存 top-3/4/5。
- Emap2lig 与 Find_1 使用不同的候选生成、选择和排序契约。两者共享 179 个 PDB、双向覆盖阈值 0.30 和 top-k 命中定义，但不能解释为逐候选配对。
- Emap2lig 不读取受体模型，所以只有一条 receptor-independent 曲线；不得复制成真实受体与 CryoAtom2 两条曲线。
- Emap2lig 不执行 Matcher 的假阳性判断或 SMILES 匹配。它的 Stage1-only 曲线不能解释为 Stage1+Matcher 性能。
- AdaLigand 已有的 Emap2lig 语义体素与实例覆盖报告不在本档案重复；本档案只保存 Matcher 比较所需的 top-k 事实和追溯链。
