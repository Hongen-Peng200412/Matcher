# 追溯与说明：blob_only-0

## 实验身份与科学契约

| 字段 | 内容 |
| --- | --- |
| 实验标识 | `blob_only-0` |
| 正式模型变体 | `blob_only` |
| 候选侧输入 | V/blob token、V 的 count/mean/max 和四项裁剪统计 |
| 明确删除的候选侧输入 | 实验密度、模拟密度、受体体素、A/P/PP token、U-Net、体素调制器和两个区域辅助头 |
| 身份侧输入 | SMI-TED 原生向量、SMILES 图增量和同一 PDB 内身份清单增量 |
| 模型输出 | 候选前景二分类，以及同一 PDB 给定 SMILES 集合内的闭集身份匹配 |
| 训练批量 | `batch_size=32`，`gradient_accumulation_steps=1`，有效全局批量 32 |

训练损失只包含权重为 0.30 的候选前景二分类损失和权重为 1.00 的 SMILES 身份交叉熵。SMILES 身份交叉熵只作用于真实前景且身份资产受支持的候选，不乘前景预测概率。两个区域损失权重均为 0，因为本模型没有区域辅助头。

BEST checkpoint 的唯一选模公式是：

```text
selection = (
    0.3 × validation 前景 PRAUC
    + 真实前景且身份受支持候选上的 SMILES 匹配准确率
) / 1.3
```

前景 F1 不参与选模。训练结束后只在最终 BEST 的 validation 预测上拟合一次前景阈值 `0.30859375`，再把该阈值写回 BEST checkpoint；正式测试只读取该冻结阈值。

扩展 top-k 对每个 PDB 先排列 `candidate_selected=True` 候选，再追加 `candidate_selected=False` 候选。Gaussian 曲线使用 `candidate_score`，来源概率均值曲线使用 `source_probability_mean`；分数相同时保持原稳定顺序，再以较小 `source_blob_index` 决胜。Stage1+Matcher 不改变 Stage1 候选顺序，只执行前景判断与 SMILES 匹配。

## 限制与解释边界

- 本轮没有读取 calibration，也没有修改 calibration 科学产物。allocation 路径中的 `calibration` 只是历史反馈目录名称。
- 测试没有重新拟合前景阈值；真实受体和 CryoAtom2 均使用 BEST validation 冻结阈值 `0.30859375`。
- `9ian` 与 `9oq7` 的相关目标缺少受支持的严格 SMILES 图和 SMI-TED 资产。对应候选仍参与前景评价并保留 Stage1 排名，但退出 SMILES 匹配准确率分母，也不能构成 Stage1+Matcher 的 SMILES 命中。
- test_1 是同一次 test_0 冻结前向对官方 149-PDB 列表的子集筛选，不是独立前向或新的模型选择数据。
- H100、A800、A100 等硬件差异只描述执行环境，不能解释为新的模型变量。
- Stage1+Matcher 比 Stage1-only 增加前景正确和 SMILES 正确条件，却不改变候选顺序；两类曲线不能按相同难度直接比较。
