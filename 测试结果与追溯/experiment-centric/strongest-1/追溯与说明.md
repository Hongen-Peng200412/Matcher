# 追溯与说明：strongest-1

## 实验身份与科学契约

`strongest-1` 的代码变体为 `strongest`。候选侧联合使用 106 通道体素、A/P/V/PP token 和候选统计；A、P、PP 各有一个初值为 `0.01` 的独立可学习标量门，V/blob 不加门。RAUNet 只输出最高分辨率解码特征，不含历史末端多尺度卷积分支。区域头仍存在，但训练损失权重为 `0.30/0.00/0.00/1.00`，因此两个区域损失不参与优化。

BEST 公式是 `(0.3 × 前景 PRAUC + SMILES 匹配准确率) / 1.3`。前景 F1 不参与选模；阈值 `0.359375` 只由 BEST validation 拟合。扩展 top-k 先 selected、后 unselected；Matcher 不改变 Stage1 顺序。
