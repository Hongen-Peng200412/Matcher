# 追溯与说明：density_only-106

## 实验身份与科学契约

`density_only-106` 的代码变体为 `density_only_106`。候选侧只构造 `(106,48,48,48)` 体素：56 通道完整密度 bank 连接 50 通道受体原子特征网格；不读取 A/P/V/PP token、人工统计或区域标签，不建立体素调制器、候选聚合器或区域头。身份侧、前景头和直接 SMILES 身份交叉熵与正式主线一致。训练损失权重为 `0.30/0.00/0.00/1.00`。

BEST 公式是 `(0.3 × 前景 PRAUC + SMILES 匹配准确率) / 1.3`。前景 F1 不参与选模；阈值 `0.396484375` 只由 BEST validation 拟合。扩展 top-k 先 selected、后 unselected；Matcher 不改变 Stage1 顺序。

## 限制与解释边界

- 没有读取 calibration，也没有在测试集拟合阈值。
- `9ian` 与 `9oq7` 参与前景评价但退出身份准确率分母。
- test_1 是 test_0 同次前向的子集筛选。
- 单通道 density_only-0 使用 A800，本实验使用 H100；二者只能作描述性比较，不能把差异严格归因于 1→106 通道。
- Stage1+Matcher 不改变候选顺序，且判定条件比 Stage1-only 更严格。
