# 追溯与说明：density_only-0

## 实验身份与科学契约

`density_only-0` 的代码变体为 `density_only`。候选侧唯一输入是 `(1,48,48,48)` 实验密度：先按 0.1%/99.9% 分位截断，再对完整网格执行 z-score；RAUNet 最高分辨率特征经空间 mean/max 和投影形成候选表示。模型不读取模拟密度、受体栅格、A/P/V/PP token、12 项模态统计、4 项裁剪统计或区域标签，也不建立体素调制器、候选聚合器和区域头。身份侧与正式主线相同。

训练损失权重为 `0.30/0.00/0.00/1.00`。SMILES 身份交叉熵只作用于真实前景且身份资产受支持的候选。BEST 选模公式为：

```text
selection = (0.3 × validation 前景 PRAUC + SMILES 匹配准确率) / 1.3
```

前景 F1 不参与选模；训练结束后只在 BEST validation 拟合一次阈值 `0.52734375`。扩展 top-k 先排列 selected、再追加 unselected；Gaussian 使用 `candidate_score`，概率均值使用 `source_probability_mean`。Stage1+Matcher 不改变候选顺序。

## 限制与解释边界

- 没有读取 calibration，也没有在测试集重新拟合阈值；路径中的 `calibration` 只是 allocation 的历史目录名。
- `9ian` 与 `9oq7` 的不受支持目标参与前景评价并保留排名，但退出身份准确率分母。
- test_1 是 test_0 同次前向的 149-PDB 子集。
- H100、A800 或 A100 差异只描述执行环境，不能解释为模型变量。
- Stage1+Matcher 增加前景和身份正确条件但不改变 Stage1 顺序，不能与 Stage1-only 按相同难度直接比较。
