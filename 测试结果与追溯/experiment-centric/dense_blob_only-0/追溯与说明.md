# 追溯与说明：dense_blob_only-0

## 实验身份与科学契约

| 字段 | 内容 |
| --- | --- |
| 实验标识 | `dense_blob_only-0` |
| 正式模型变体 | `density_blob_only` |
| 模型输入 | 单通道归一化实验密度 U-Net；V/blob 候选 token；V 的 count/mean/max 和四项裁剪统计；SMI-TED 原生向量、SMILES 图增量和同一 PDB 内身份清单增量 |
| 明确删除的输入 | 模拟密度、受体 hardmask、50 维受体原子栅格，以及 A/P/PP token |
| 模型输出 | 候选前景二分类，以及同一 PDB 给定 SMILES 集合内的闭集身份匹配 |
| 训练批量 | `batch_size=32`，`gradient_accumulation_steps=1`，有效全局批量 32 |

训练损失由候选前景二分类损失、SMILES 身份交叉熵和两个权重均为 0.10 的区域辅助损失组成。SMILES 身份交叉熵只作用于真实前景且身份资产受支持的候选，不乘前景预测概率。

BEST checkpoint 的唯一选模公式是：

```text
selection = (
    validation 前景 PRAUC
    + 真实前景且身份受支持候选上的 SMILES 匹配准确率
) / 2
```

前景 F1 不参与选模。训练结束后只在最终 BEST 的 validation 预测上拟合一次前景阈值 `0.248046875`，再把该阈值写回 BEST checkpoint；正式测试只读取该冻结阈值。

扩展 top-k 对每个 PDB 执行以下唯一排序：先在 `candidate_selected=True` 候选内按指定分数降序排列，再在 `candidate_selected=False` 候选内按同一分数降序排列，最后连接两段。Gaussian 曲线使用 `candidate_score`，来源概率均值曲线使用 `source_probability_mean`；分数相同时保留原稳定顺序，再以较小的 `source_blob_index` 决胜。Stage1+Matcher 不改变 Stage1 候选顺序，只在该顺序上执行前景判断和 SMILES 匹配。

## 限制与解释边界

- 本轮整理没有读取 calibration，也没有修改任何 calibration 产物。allocation 与 launch 路径中含有 `calibration` 字样只是历史反馈目录名称，不能视为读取了其中的科学数据。
- 测试没有重新拟合前景阈值；真实受体和 CryoAtom2 均使用 BEST validation 冻结阈值 `0.248046875`。
- `9ian` 与 `9oq7` 的相关目标缺少受支持的严格 SMILES 图和 SMI-TED 资产。对应候选仍参与前景评价并保留 Stage1 排名，但退出 SMILES 匹配准确率分母，也不能构成 Stage1+Matcher 的 SMILES 命中。
- test_1 是同一次 test_0 冻结前向对官方 149-PDB 列表的子集筛选，不是独立前向或新的模型选择数据。
- H100、A800、A100 等硬件差异只描述执行环境，不能解释为新的模型变量，也不能据此把跨硬件数值差异归因于模型结构。
- Stage1+Matcher 曲线比 Stage1-only 增加了前景正确和 SMILES 正确的条件，却不改变候选顺序；两类曲线不能按相同难度直接评价排序优劣。
